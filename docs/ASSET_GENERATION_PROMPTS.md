# Cherry Bloom — Asset Generation Prompts

These prompts document the intended art direction so assets can be regenerated consistently if needed.

## Concept board
Create a polished mobile-game visual design board for an original game called “Cherry Bloom”. Show: logo, Cherri cherry protagonist, idle/jump/fall/collision states, four environments (First Bloom dawn, Sakura Garden daytime, Golden Bloom sunset, Yozakura night), flowering branch obstacles, Welcome/How To Play/Game/Game Over/Credits screen concepts, primary/secondary buttons, score HUD, petals and icon language. Rounded premium 2D game art, cherry red + blossom pink + cream + leaf green + violet night palette, crisp readable forms, no copyrighted characters, no Flappy Bird art.

## Character sheet
Create a transparent-background 2×4 sprite/reference sheet of one consistent original cherry mascot named Cherri. Single glossy cherry body, curved brown stem, green leaf, tiny black eyes and minimal mouth. States: idle, happy/jump, falling/tilted, wink, collision/squash, dizzy, celebrate with petals, neutral. Maintain identical proportions and colors across states. No text.

## Four-phase environment sheet
Create four equal vertical panels of the same side-scrolling blossom garden world with a clear gameplay corridor: First Bloom dawn, Sakura Garden daylight, Golden Bloom sunset, Yozakura night. Layered mountains, distant bridge/garden silhouettes, flowering branches framing edges, drifting petals. No characters and no text. Maintain the same composition across phases so lighting/time is the primary change.

## Production warning
Generated concept images may contain visual inconsistencies or hallucinated text. Never copy text, hex values or gameplay rules from the image itself; use the MD specifications as authority.
